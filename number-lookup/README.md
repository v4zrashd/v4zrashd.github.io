# V4Z RASHD Number Lookup

Small static page for checking basic Bangladesh mobile number info through the number-lookup worker API.

## Safety choice

No API key is embedded in this site. The key from the bot command export was not copied into GitHub. For a live test, paste your own key in the browser field on the page.

## Usage

1. Open the GitHub Pages URL after Pages is enabled for the repo.
2. Enter an 11-digit Bangladesh mobile number (`013`–`019`).
3. Paste your own API key in the browser only.
4. Tap **Lookup**.

Demo mode shows sample UI data without calling the API.
